# Changelog: Настройка Marlin 2.1.2.8 под MKS Robin Nano V3.1 (EDM)

## 🔌 Аппаратная часть (Hardware)
* **Микрошаг:** Выбрано деление **1/32**. Для этого на плате под каждым драйвером необходимо установить **все 3 джампера** (M0, M1, M2).

## Структура проекта
* **Расположение файлов:** Конфигурационные файлы `Configuration.h` и `Configuration_adv.h` перенесены в целевую системную папку по пути `📂 Marlin/`.

## 🛠 Изменения в `platformio.ini`
* **Окружение сборки (`default_envs`):** Значение `mega2560` заменено на `mks_robin_nano_v3_1_usb_flash_drive_msc`.
* **Результат:** Включена компиляция под чип STM32F407VET6. Активирован режим **USB MSC**, при котором плата определяется компьютером как обычный накопитель (картридер).

## Изменения в `Marlin/Configuration.h`

### 1. Системные настройки
* **Материнская плата:** 
  ```cpp
  #define MOTHERBOARD BOARD_MKS_ROBIN_NANO_V3_1
  ```
* **Интерфейсы связи:** Настроен USB-порт платы и раскомментирован порт для дисплея:
  ```cpp
  #define SERIAL_PORT   -1
  #define SERIAL_PORT_2  1
  ```

### 2. Конфигурация драйверов
* **Тип шаговиков:** Стандартные `A4988` заменены на ваши под оси X, Y и Z:
  ```cpp
  #define X_DRIVER_TYPE  DRV8825
  #define Y_DRIVER_TYPE  DRV8825
  #define Z_DRIVER_TYPE  DRV8825
  ```

### 3. Адаптация под EDM (Электроэрозию)
* **Отключение термодатчиков:** Выключен опрос термисторов хотенда и стола, чтобы плата не уходила в защиту `Thermal Runaway`:
  ```cpp
  #define TEMP_SENSOR_0   0
  #define TEMP_SENSOR_BED 0
  ```
* **Разблокировка движения:** Снята блокировка моторов при работе «на холодную»:
  ```cpp
  //#define PREVENT_COLD_EXTRUSION
  ```
* **Логика концевиков:** Подготовлен блок инвертирования концевых выключателей (`_MIN_ENDSTOP_INVERTING`) для последующей интеграции с датчиком контроля дуги / компаратором.


# G-code
* M211 S0 - Относительная система отсчета, за 0 берем текущее положение
* G1 X50 F1200 - Двигаем ось X на 50 мм со скоростью 1200 мм/мин
* M201 X100 - Установить максимальное ускорение оси X на 100 мм/с²
* M204 P100 - Установить ускорение для штатных перемещений на 100 мм/с²
